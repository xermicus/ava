Before pushing, it tested the heuristic locally and hit scoring timed out (tool result at line 40) — the scoring container was still running prepare() (the round-robin that computes the field's ELO ratings) when the request landed; score.error.log shows a SIGTERM mid-evaluation and the field ratings being recomputed a few seconds later. The proxy log independently shows a 500 from the score host that took 137s to fail. This is environment noise from hitting the scorer before it had finished warming up, not something the agent caused, and it resolved itself once the field was ready.

While testing, the agent also caught its own bug: DIV r1, r1, r3 used r3 after it had already been overwritten earlier in the program, corrupting the divisor. It fixed this with a dedicated register holding a literal 3 (call 44) before the first real push, so no push ever faulted.

The first git push ("Initial heuristic bot") landed at 265s, rating 861 (score.log, run.json attempts[0]), field capped at 1201.

Why it passed

Every recorded push in score.log and run.json.attempts is "passed": true, and score.error.log confirms 0 faults, 0 cycle budget overruns on all of them — the program always produced a SCORE for every legal move within the 20M-cycle budget, satisfying chess-vm's only failure condition (fault or cycle exhaustion). Because the game ranks purely by the rating of the best passing push, and the agent's tuning loop only ever adopted variants that measurably beat the current best, the final entry (1213) is also the strongest, so the run banked its best result and did not need a last-call scramble.

Assessment

This is a clean pass with no environment-caused damage: the one hiccup (scorer warming up) was transient and self-resolved via a normal retry. The agent's own process — hypothesize a heuristic term, test many weight values locally and in parallel, commit only real improvements — is exactly the loop the game rewards, given that a chess-vm submission cannot search and must be tuned by measurement. Pacing was good: a valid pass was banked at 7% of the time budget, and the best pass at 69%, leaving comfortable margin instead of a last-call push.
