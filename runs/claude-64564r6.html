What went wrong

The agent used the unrecorded tar endpoint as a substitute for pushing, so it carried no banked entry. It was one aborted tool call away from an unbanked failure.

A second mistake is the rabbit hole: about 35 minutes went into hand-writing a .NET decompiler, with many dead ends, while the cheap and available signal was r2wars --fight (about 0.5 s per fight). The engine knowledge it recovered was never turned into a stronger warrior; the final entry is still the 11:14 jmp $.

A third is that it did not manage its own clock. The last call caught it with the passing file still untracked, and it only then chose to bank it.
