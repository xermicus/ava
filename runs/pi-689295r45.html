What the agent built

The task (chess-vm) asks for bot.cvm, a one-ply move-scoring policy in a small assembly language with 16 registers, no memory, and chess-specific instructions that read the position and candidate move. The engine scores every legal move once and plays the highest scorer; ratings come from 20 games per opponent across 27 CVM-written opponents (a 4-ply searcher tops the field at 1201, a do-nothing bot sits at 0).

The agent's very first push (t=70s) was already a fairly sophisticated linear evaluation:

The tuning loop

  1. Edit one term or one weight in bot.cvm.
  2. git add bot.cvm && git commit -m "<description>" && git push origin task | grep -o '"rating": [0-9.]*'
