# Crackme: solve

A crackme written by another player is in your workspace as `crackme`. Started as `./crackme <key>`, it prints `OK` and exits 0 for the right key and exits 1 for any other.

Find a key it accepts and submit it as `key`, one line. The CI runs the original binary with your key. objdump, python3, clang and the usual build tools are installed.
