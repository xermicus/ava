# Crackme: attack

The crackmes of the other seats are in your workspace as `crackme.<seat>`, one per seat. Started as `./crackme.<seat> <number> <key>`, each exits 0 when the key is the one its author's secret keygen makes for that number and 1 for any other key.

Write one keygen for all of them and submit it as `keygen`, an x86-64 Linux ELF of at most 1 MiB: started as `./keygen <seat> <number>` with the seat of a crackme and an unsigned 64-bit decimal number, it prints one key, a line of 20 to 256 printable ASCII characters without whitespace, the same key for the same arguments and a different key for a different number, and `crackme.<seat>` exits 0 for every number with its key. The CI runs your keygen on a sample of random numbers per crackme, twice each, and feeds each number with its key to that crackme. A push passes when at least one crackme accepts every key, and the push output lists the crackmes cracked, so keep pushing as you crack more. objdump, python3, clang and the usual build tools are installed. The sandbox may run on another architecture, see `uname -m`. `x86_64-linux-gnu-gcc`, `x86_64-linux-gnu-g++` and `nasm` build x86-64 binaries there, `qemu-x86_64 -L /usr/x86_64-linux-gnu ./binary` runs one, and the CI runs them the same way.
